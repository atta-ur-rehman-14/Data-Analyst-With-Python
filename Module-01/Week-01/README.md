# Week 01 — Python Fundamentals

**Module:** Module-01  
**Course:** Data Analyst with Python  
**Week:** 01  
**Focus:** Core Python syntax, data handling, and basic problem-solving

---

## Overview

This week introduces the foundational concepts required to work with Python. Learners will become familiar with Python syntax, variables, data types, operators, user input, and basic data structures. The material is organized into three files: two Jupyter notebooks and one standalone Python script.

---

## Learning Outcomes

By the end of this week, learners should be able to:

- Write and execute basic Python statements
- Understand and use variables to store data
- Identify Python data types: integer, float, string, and boolean
- Use the `type()` function to inspect data types
- Format output using `print()` with newlines, tab characters, and custom endings
- Apply bitwise, arithmetic, comparison, logical, and assignment operators
- Accept user input and convert input data types
- Create and access lists

## Topics Covered

### Class 01 — Core Python Concepts

- Printing text, numbers, and variables
- Creating and reassigning variables
- Python data types: `int`, `float`, `str`, and `bool`
- Inspecting data types with `type()`

### Class 02 — Operators, Input, and Lists

- Output formatting using `\n`, `\t`, and `end`
- Bitwise operators and binary representation
- Arithmetic and comparison operators
- Logical operators: `and`, `or`, and `not`
- Assignment operators: `=`, `+=`, `-=`, `*=`, `%=`
- Taking input with `input()`
- Converting strings to integers
- Creating and indexing lists

## How to Run

### Run the Jupyter notebooks

From the repository root:

```bash
cd Module-01/Week-01
jupyter notebook
```

Then open either `Class-01.ipynb` or `Class-02.ipynb` in your browser.

### Run the Python script

```bash
cd Module-01/Week-01
python Class-01.py
```
